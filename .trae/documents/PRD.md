## 1. 产品概述

面向口腔医学生和新入职助理医生的影像报告闯关训练纯前端应用，将影像报告书写训练从口头点评变为可练、可看进步的轻量教学工具。通过趣味关卡式练习，学生按牙位、影像所见、初步判断、建议处理四栏填写报告，系统自动逐项比对标准答案并指出常见问题，错题按类型归类支持反复重做。

- 目标用户：口腔医学院在校学生、新入职口腔科助理医生、科室带教老师
- 核心价值：让影像报告训练变得可量化、可追踪、可反复练习，降低带教成本

## 2. 核心功能

### 2.1 用户角色

| 角色 | 使用方式 | 核心权限 |
|------|----------|----------|
| 学生 | 直接使用 | 选择关卡、填写报告、查看批改、回顾错题、重做练习 |
| 带教老师（预留） | 直接使用 | 查看学生进度统计（当前版本为纯前端，暂不做登录区分） |

### 2.2 功能模块

1. **关卡选择页（首页）**：关卡地图/列表、进度展示、关卡主题说明
2. **练习页**：影像展示、主诉信息、四栏报告填写表单
3. **批改页**：逐项比对结果、错误标注、改写示例、得分展示
4. **错题页**：按错误类型分类、错题详情、重做入口

### 2.3 页面详情

| 页面名称 | 模块名称 | 功能描述 |
|----------|----------|----------|
| 关卡选择页 | 关卡地图 | 展示4大主题关卡：龋坏邻面片、根尖周病、阻生智齿、牙周骨吸收，每关含2-3个病例 |
| 关卡选择页 | 进度统计 | 展示各关卡完成状态、最佳得分、星级评价 |
| 关卡选择页 | 总体进度 | 显示整体完成度和错题数量 |
| 练习页 | 影像展示区 | 展示脱敏口腔影像（占位图），支持放大查看 |
| 练习页 | 主诉信息栏 | 显示患者基本信息和主诉描述 |
| 练习页 | 报告填写表单 | 四栏输入：牙位、影像所见、初步判断、建议处理，带填写提示 |
| 练习页 | 计时器 | 记录答题用时 |

| 错题页 | 重做功能 | 一键重做同类病例，回到练习页 |

## 3. 核心流程

学生打开应用后，在关卡选择页浏览可用关卡和自身进度。选择一个关卡进入练习页，查看脱敏影像和主诉后，在四栏表单中填写报告。提交后进入批改页，查看逐项比对结果、得分和改写建议。错误的题目自动归入错题页，学生可在错题页按错误类型筛选，选择重做同类病例。

```mermaid
flowchart TD
    "A[关卡选择页]" --> "B[选择关卡]"
    "B" --> "C[练习页]"

    "D" --> "E[填写四栏报告]"
    "E" --> "F[提交报告]"
    "F" --> "G[批改页]"
    "G" --> "H{有错误？}"
    "H" --> "是" --> "I[错误归入错题本]"
    "H" --> "否" --> "J[显示满分通过]"
    "I" --> "K[查看改写示例]"
    "J" --> "L[返回关卡选择]"
    "K" --> "L"
    "L" --> "M[错题页]"
    "M" --> "N[按类型筛选错题]"
    "N" --> "O[选择重做]"
    "O" --> "C"
```

## 4. 用户界面设计

### 4.1 设计风格

- **主色调**：深青色（#0D7377）+ 暖白背景（#FAFAF8），搭配珊瑚色（#E8634A）作为强调色
- **辅助色**：浅灰（#E8E8E6）用于卡片背景，深灰（#2D3436）用于正文
- **按钮风格**：圆角（8px），主按钮实心填充，次按钮描边，带悬停微动效
- **字体**：标题使用 Noto Serif SC（衬线体，医学文献质感），正文使用 Noto Sans SC
- **布局风格**：桌面端左右分栏（影像+表单），移动端上下排列，卡片式关卡展示
- **图标风格**：线性图标（lucide-react），配合牙科主题装饰元素
- **整体氛围**：专业但不冰冷，像一本精美的医学教科书，带一点闯关游戏的进度感和成就感

### 4.2 页面设计概览

| 页面名称 | 模块名称 | UI元素 |
|----------|----------|--------|
| 关卡选择页 | 关卡地图 | 卡片网格布局，每张卡片含关卡图标、标题、进度条、星级、锁定/解锁状态 |
| 关卡选择页 | 进度统计 | 顶部横向统计条：已完成X关、总得分、错题数 |
| 练习页 | 影像展示区 | 左侧大面积影像展示区，支持hover放大，底色深灰模拟观片灯 |
| 练习页 | 主诉信息栏 | 影像下方信息条，半透明背景覆盖 |
| 练习页 | 报告填写表单 | 右侧四栏纵向排列，每栏含标签、文本域、字数统计 |
| 练习页 | 计时器 | 右上角计时显示 |
| 批改页 | 得分展示 | 顶部大号得分+星级+用时，动画弹出 |
| 批改页 | 逐项比对 | 中间区域四栏对比，绿色✓正确、黄色△部分正确、红色✗错误 |
| 批改页 | 改写示例 | 每项错误下方展开改写建议，蓝色高亮改写部分 |
| 错题页 | 类型筛选 | 顶部标签栏，点击切换错误类型 |
| 错题页 | 错题卡片 | 瀑布流卡片，含缩略图、关卡名、错误类型标签、错误摘要 |
| 错题页 | 重做按钮 | 卡片底部醒目按钮 |

### 4.3 响应式设计

- 桌面优先设计（1280px+）
- 平板端（768px-1279px）：练习页改为上下排列，影像在上表单在下
- 移动端（<768px）：单列布局，关卡卡片横向滑动，表单全宽
